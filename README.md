This extension removes this ghastly banner from your Magento 2 store if you're Smile's Elasticsuite:

![image](https://github.com/user-attachments/assets/2513a6a5-1ae8-4cf7-b316-fca2cb431f10)



## Versions

- `1.2.x` supports Elasticsuite 2.12 and later. It removes the Premium upsell notice, the telemetry notices on the admin dashboard and the Elasticsuite RSS feed in the admin notification inbox. Elasticsuite's healthchecks are left alone.
- `1.1.x` supports Elasticsuite 2.11 and earlier, which showed the version notice as an admin system message.
